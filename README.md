# Student Management System

A console-based Student Management System built using Java.

## Features
- Add student records
- View all students
- Search students by ID
- Delete student records
- Calculate average marks
- Sort students by marks
- Save and load records using file handling

## Concepts Used
- Java Fundamentals
- Object-Oriented Programming
- Classes and Objects
- Constructors and Encapsulation
- ArrayList and Collections
- Loops and Conditional Statements
- Methods
- Exception Handling
- File Handling
- Lambda Expressions
- Sorting and Comparators

## Technologies
- Java
- JDK 27
- VS Code

## How to Run

```bash
javac Main.java
java Main
```

## Purpose

Built as a beginner Java project to practise programming fundamentals and understand how different Java concepts work together.
